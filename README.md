# 🌻 Nat

Una página especial dedicada a alguien muy especial. Hecha con HTML, CSS y JavaScript.

## 📋 Contenido

- `index.html` - Página principal
- `styles.css` - Estilos de la página
- `script.js` - Interactividad (nubes, flores, mariposas, polaroids)
- `README.md` - Este archivo

## 🚀 GitHub Pages - Instalación

Para ver esta página en internet a través de GitHub Pages, sigue estos pasos:

### 1. Ir a Settings del repositorio
- En tu repositorio en GitHub.com, ve a **Settings**
- En la barra lateral izquierda, busca **Pages** (en la sección "Code and automation")

### 2. Configurar la fuente
- En **Source**, selecciona **Deploy from a branch**
- Rama: `main`
- Carpeta: `/ (root)`
- Haz clic en **Save**

### 3. ¡Listo!
GitHub Pages automáticamente publicará tu sitio en: `https://Dyn0809.github.io/Nat`

Puede tomar unos minutos en aparecer si es la primera vez. 🎉

## 💡 Características

## 🛠️ Cómo personalizar

- **Cambiar el mensaje**: Edita el `<h1>` y `<p>` en `index.html`
- **Cambiar colores**: Modifica los valores en `styles.css` (busca gradientes)
- **Cambiar animaciones**: Edita `script.js` para alterar el comportamiento
